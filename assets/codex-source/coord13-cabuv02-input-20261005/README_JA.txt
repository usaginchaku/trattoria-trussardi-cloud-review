CABUV02 — 採用済みC4家具の追加188面、UV2だけの修正入力

native_mesh.jsonが自作一家具の正本です。JSONだけをPython/Blender 4.3等で読み取れます。
FBX/Unity本体/元blend/原作画像/テクスチャ画像/作業履歴は同梱しません。
UV2はUnityの第2UVチャンネルです。UV0とは別です。入力や原本を上書きしないでください。

現nativeは9441頂点・4408三角形・1材スロットです。編集可能なのは追加頂点9039〜9440のUV2計402行のみ。
追加三角形4220〜4407の188面は、既存面とUV2三隅がFloat32 bitで完全一致し、重複しています。
追加面と既存面は頂点indexを共有していないため、この402行だけを更新できます。
全P/N/T（w含む）/UV0/頂点・index順/位相/材/姿勢を固定。UV2の既存0〜9038も固定です。
既存面に面積0のUV2が72面ありますが別残件です。本依頼で勝手に修正しないでください。

単位・軸・材slot・既存GIとの測定境界はnative_mesh.jsonとedit_scope.jsonを参照してください。
nativeの上方向は-Zです。UV2を作るために表示用に座標変換しても、返す値は元native vertexId対応のUV2だけです。
法線や接線の再計算、vertex split/weld、全体unwrap、密度条件の無断緩和は禁止です。

成果物はcandidate_uv2_patch.jsonと簡潔なQAです。edit_scope.jsonの出力schema/条件に従い、
追加面内・既存面との正面積重複、面積、最小余白、密度と歪みの制約を数値で説明してください。
ベイク解像度・必要pixel余白・密度目標は未確定です。normalized UV余白を明示し、不足があればHOLDを返してください。
技術上の収容と見た目・実ベイク適合は別判定です。既存GIを流用して問題が解消したとは主張しないでください。
