■ 比較の方法
- モデル側の数値は blend から正確に測った(qa/curved_L1_model_metrics.json)。
- 資料側の数値は、画面上の見かけの比を目で読んだ値(qa/curved_arm_comparison.json)。左右 2 灯の値を両方記録した。
  - 読み取りの誤差は、カップ高さ Hs の ±0.05 程度。
  - 下から斜めに見ているので、水平方向の比は低確度。縦の比は、カップの高さ Hs かカップの幅 Ws を基準にした。
- 資料と似た角度(横 50〜80°、下から 10〜25°)でモデルを見たときの見え方は、scratch で確認しただけで、納品していない。

■ 結果(モデル L1 と資料の見かけの値の平均)
- 一致しているもの:
  - 取付け板の高さ / Hs: 0.85 と 0.87
  - 腕の太さ / Ws: 0.108 と 0.10
  - 腕が U から J の字であること自体(既に存在する)
- 主な差(取付け板とカップの上下の関係。要因は 1 つで、左右の資料とも同じ傾向):
  - 板の上端(カラーの下端を基準): -0.05 と +0.26 Hs
  - 板の下端(同じ基準): -0.90 と -0.62 Hs
  - 資料では、板全体が、カラーに対しておよそ 0.29 Hs(Ws 基準でも約 0.33 Ws)高い位置にある。基準を Hs と Ws のどちらにしても、差は残る。
- 腕の出口(同じ基準): -0.36 と +0.04 Hs
  - 資料では、腕の出口がモデルの板の上端よりも上にある。板を保持したままでは、腕だけを変えても再現できない。
- 腕だけの差(板の位置の差を除いたあとに残るもの):
  - 板の中での出口の位置(上端からの比): 0.36 と 0.25(約 0.1、およそ 1.8 cm)
  - 底の深さ: 板の位置の差を除くと、約 0.1 Hs
  - どちらも読み取りの誤差の 2 倍程度で、資料の線は板と重なって描かれているため、確度は低い。腕だけの「明確な差」とは言えない。
- 別の要因(今回は扱わない):
  - カラーの幅 / Ws: 0.48 と 0.35
  - カップの幅÷高さ: 1.05(L1 の決定)と 0.89
- 底の位置(腕の届く範囲に対する比): 0.375 と 0.46。斜めからの投影なので低確度で、ほぼ一致として扱う。

■ C1 を作らない理由
- 指示は「腕の輪郭の明確な差が示せた場合に限る」で、カップ、カラー、取付け板、原点は保持する条件。
- 最も大きな差(約 0.3 Hs)は、取付け板とカップの上下の関係。腕だけを変えても直らない。
- 腕だけで変えられる差(出口の高さと深さ、約 0.1 Hs)は、誤差の範囲に近い。
- 既存の L1 には U から J の腕が既にあるので、腕を作り直しても「改善」とは言えない。

■ 切り分け(次の判断のための候補。どれもまだ実施していない)
- F1 板と腕のまとまりを、カップとカラーに対して約 0.3 Hs(L1 の寸法で約 6 cm)上げる。
  - 原点が「取付け板の底」なので、カップの位置が原点に対して下がることになり、設置の高さの判断と結び付く。
  - 元Codex と指示役の配置の判断が必要。
- F2 腕の出口を板の上側(上端から 0.25)に移し、底を少し深くする。F1 の後でないと評価できない。
- F3 カラーを細くする(0.48 → 0.35 Ws 程度)。カラーは別の部品で、別の要因。
- F4 カップの比率(L1 の 1.05 と資料の見かけの 0.89)。L1 で決めたことで、今回は変えない。
- 必要な最小の追加確認:
  - 指示役による、上下の関係の再読み取り(DU_ep10-4 は下からの見上げで、縦の比は比較的強いが、カラーの下端の読み取りに誤差がある)
  - ローカル Unity で、同じ角度から現行の配置を見た比較
