COORD12 次のモデリング仕様(Claude 担当、入力が届いてから別の未使用フォルダで造形する。今回は作らない)

1. 見える根拠(DU_ep10-4。詳細は README_JA)
- 2 種類がある:
  - A 壁付カップ: 短い腕、取付け板はカップの下で左寄り。
  - B 湾曲アーム: U 字の腕、取付け板は縦長でカップの横。
- カップは共通の構成: 上がわずかに広い円筒部(約 65%)+ 水平の境目 + 丸い椀部(約 35%)+ 下のカラー。
- 材質は 2 つ: カップ(クリーム、不透明に見える)と金具(暗いオリーブからブロンズ)。境目はカップとカラーの接合部。
- B の取付け板は縦長の長方形(高さ ≈ カップの幅、幅 ≈ 0.27 倍、縁に段)。腕の太さ ≈ カップの幅の 0.1 倍。U の底はカラーよりカップ高さの約 0.6 倍下。

2. 分からない所(推測で確定しない)
- 実寸、取付けの高さ、壁からの出
- カップ上面の開口と内面(見えない)
- 光源の位置
- 腕の断面と取付け板の厚み
- A の左の灯具の形(遮蔽)
- 暖炉側の瓶棚の左にある灯具の形(映っていない)
- A と B のカップの比率の差(0.9〜1.0)が実際の差か、見え方の差か
- 「厨房口」と DU_ep10-4 の扉口の対応

3. 保持すべき入力チャンネル(元Codex の限定入力が届いたら、最初に記録する)
- object の名前、原点、ローカルの軸の向き(壁の法線方向)、取付け面の位置
- 外寸
- material slot の数・名前・順番、各 slot が割り当たる部位(カップと金具)
- texture のファイル名と参照形式(basename、相対)
- UV 層の名前と数、lightmap 用の UV の有無
- 法線の方式(custom の有無)、三角形数
- shell の構成(カップ、カラー、腕、取付け板)
- FBX のヘッダ(UnitScaleFactor、軸、Lcl)
- 光源の配置との関係(Unity 側の light の位置。モデルとは別に記録)
- 倍率 0.7825509309768677 と、仗助 180 cm / エク 160 cm を前提にした配置は、後工程で扱う。モデルには焼き込まない。

4. 比較案(同じ条件で、原作の画素は入れない)
- 入力と候補を、同じカメラ・光・材質(入力の texture をそのまま)・描画で並べる。
- 視点:
  - 正面(壁の法線方向、正投影)
  - 側面(壁と平行、正投影)。A の短い腕の角度や、B の U 字腕の出と取付け板からの距離を見る。
  - 斜め下(人の目の高さから見上げ。DU_ep10-4 の見え方に近い)
- 配置や光のレイアウトは触らない。

5. 検査(独立スクリプト、再 import して照合)
- 閉じた形状: 非多様体 0、境界の辺 0(開口部を意図して作る場合は、その縁だけを許し、数を記録する)
- 面積 0 の面が 0、長さ 0 の法線が 0、custom 法線の単位長
- UV: 層名が同じ、0〜1 の範囲、変えていない shell は UV が一致
- 変えていない shell: 位置、UV、loop 法線が一致(許容差を明記)
- 外寸、接地(取付け面)、原点、向き、material slot の順番、三角形数の前後
- FBX: 通常の export で、'B' 型の property が 0、ローカルの path 文字列が 0。blend の画像参照は '//basename'。別のディレクトリにコピーし、新しいプロセスで開いて解決できることを確認する(REG03 の手順)。

6. 材質を固定した形状候補 1 件(入力が届いてからの予定。数値は入力で確定する)
- 対象: B の湾曲アーム灯具 1 種だけ(見える根拠が最も多いため)。
- 変える要因: 腕の形 1 つだけ(取付け板から下へ下がり、U 字に曲がってカラーへ立ち上がる輪郭)。
  - 太さの比 ≈ 0.1、U の底の深さ ≈ カップ高さの 0.6 倍は、入力の現状と比べてから、近づける量を決める。
- 保持するもの: カップ、カラー、取付け板の形と位置、材質、texture、UV(腕以外)、原点、向き、外寸の扱い(変わる場合は量を記録する)。
- 新しい腕の UV と法線だけを局所的に設ける。全体の再法線化や UV の作り直しはしない。
- A のカップ灯具と、暖炉側の灯具は、根拠が増えるまで変えない。
- COORD09 の L1(カップの円筒部を縮める案)とは別の要因なので、混ぜない。
