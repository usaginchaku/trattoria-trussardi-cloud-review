■ 色の決め方(候補としての解釈。完全一致とは言わない)
- 資料の絶対 RGB は目標にしていない。根拠は ART06P で記録した相対値だけ。
  - 色相の差 = 資料の F19 マットの色相 − F17/F18 マットの色相の平均 = 249.2 − 55.95 = +193.25°
  - 彩度の比 = 資料の F19 マットの彩度 ÷ F17/F18 マットの彩度の平均 = 0.057 / 0.128 = 0.445
- この差と比を、モデル側で F17/F18 のマットに当たる tile4 のクリーム色(HSV 47.5°, 0.1035, 0.910)に当てはめた。
  - 目標の色相: 240.75°
  - 目標の彩度: 0.0461
  - V(最大チャンネル)は tile5 の元の平均値 0.8235 のまま。
- 方法: RGB の平均だけを移す。新しい画素 = 元の画素 − 元の平均 + 目標の平均(丸めのみ、クリップは 0 件)。
  - 画素ごとの濃淡の差はそのまま残る(std は 0.584 で変わらず、min/max の幅も同じ)。
  - 画像全体の明るさ補正はしていない。
- 結果(tile5 の平均):
  - 変更前: (186, 199, 210)、HSV 207.5° / 0.114 / 0.824
  - 変更後: (200, 200, 210)、HSV 240.0° / 0.048 / 0.824
- 8bit に丸めたため、色相は 240.75° ではなく 240.0° になった。R と G が同じ値なので、赤みの入ったラベンダーではなく、青紫寄りの灰色に近い。もっと紫に寄せるかどうかは、実際のライトで判断する必要がある(元Codex / 指示役)。
- 明度の差(Rec.709 luma の平均): 197.03 → 200.72(+3.69)。V は保ったが、R が上がった分だけ luma がわずかに上がる。

■ 検証(qa/verify_art06.json)
- 変更画素は 65536 で、すべて tile5 の中。tile5 の外の変更は 0。
- マスクは 0/255 だけで、変更画素と一致する。
- 他の 15 セルは、展開した画素で完全に同じ。tile1 の背面、tile3 の外枠、tile4 の内側の縁も含む。
- モードと寸法は入力と同じ。

■ 変更していないもの
FBX、mesh、法線、UV、slot、配置、入力の原本、共有 FinishAtlas、ART05 の絵柄。slot の分割や他の renderer の修正もしていない。

■ 不確実な点
- Unity と Blender 5.2.2 は実行していない。プレビューは pip bpy 4.3.0(Cycles CPU)の参考画像。
- sampler と mipmap: tile5 だけを変えたので、隣のセル(tile4 / tile6 / tile1 / tile9)との境界で、低い mip レベルやバイリニア補間で色がにじむ可能性がある。F19 の面の UV はセルのほぼ全体を使う。
- 共有材質: F19 の slot0 材質を F19 専用に複製するのが前提。シーン全体で、tile5 を使う他の renderer の有無と材質の共有状況は確認していない(入力 FBX 3 点の範囲でだけ、tile5 は F19 のマット 12 面に限られる)。
- native UV0 の確認は元Codex が担当している。
- 統合と採用は、元Codex のローカル検証(native UV0、共有材質、sampler の非波及)と、ローカルの同条件の画像比較を待つ。
