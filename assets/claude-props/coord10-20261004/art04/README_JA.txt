■ A5 (溝なし・木枠だけ太く)  A5/
 - 木枠の内縁を 0.027 → 0.042m(左右上下とも+0.015m)。明るい帯は 0.028 → 0.0133m。木枠:マット = 3.2(資料の 2.4〜3.5 の範囲内)。
 - 方法: 外縁からの距離 d に、縦横共通の区分線形写像 g(d) を掛けた。ベベル群は形を変えずに平行移動し、平らな帯だけを伸縮させる。
     木枠の平らな帯 ×1.746(外帯 8.7→15.2mm、内帯 11.4→19.9mm)、クリーム縁の平面とマットの見え幅 ×0.372。
   縦横に同じ g を使うので、留めの角(マイター)は直線のまま。
 - 内部のマット境界の移動(明記): クリーム縁(内側リム)は外縁 d 0.026→0.041、内縁 d 0.0377→0.0487。
   マット板の外周は d 0.0364→0.0474。絵の縁 d 0.0552 は不変。
 - 不変のもの: 絵の板(8頂点)の位置・サイズ、柄、額色/素材、UV、トポロジ(2444tri)、外寸、厚み、原点/軸、取付面(y=0)。
   面の向きも変わらない(平面内の伸縮と剛体移動のみ)。カスタム法線は元の値を再設定した。
 - 動いた頂点は 920/1208(木枠・縁・マット板の内側寄り)。新しい頂点・面はない。

■ A6 (A5 + 少数の浅い溝)  A6/
 - 溝の向きは資料どおりバーを横切る向き。左右 各5本(z 0.075〜0.445、間隔 0.0925m)、上下 各5本(x ±0.096/±0.048/0、間隔 0.048m)、計20本。
   V字、幅 3mm、深さ 1.5mm。
 - 範囲: 前面の平らな2つの帯(y −0.036 / −0.031)の内側だけ。帯の端から 1.2mm 手前で止め、ベベル・側面・背面へは走らせない。
   押し込んだのは溝底の116頂点だけ(A5の表面から 0.1mm 以上離れる頂点はこの116個のみ。qa/surface_A6_vs_A5.json)。
 - 帯の外の面には、辺上に同一直線の頂点が入るだけ。その n 角形 96 個は中心点で扇分割し、ゼロ面積三角形を避けた。
 - 三角形 2444 → 3836(原本の1.57倍、目安の4000以内)。退化面 0、非多様体辺 52 / 境界辺 0 はソースと同じ。
 - 根拠と推定:
   上下の間隔 0.048m = 絵の幅の 0.20倍。資料の下バー(30px / 絵 156px)と同じ横方向の比。
   左右の間隔は、資料の方が密(遠近の不明さを含めて木枠幅の 0.4〜0.8倍)。格子に見えないよう、少数(5本)へ意図的に減らした。
   上バーは写真の外なので、本数・有無は推定(上下対称を仮定)。深さ 1.5mm も推定。隅の扇状の線は未表現。
 - 作成過程で直した点:
   (1) 溝の外の大きな三角形が溝頂点に引かれて、右上の角に斜めのむらが出た。押し込みは、つながる面が溝の帯(t±1.5mm)内だけの頂点に限定して解消。
   (2) バーの判定を、面の頂点範囲(外縁から0.06m以内)ベースに変更。
