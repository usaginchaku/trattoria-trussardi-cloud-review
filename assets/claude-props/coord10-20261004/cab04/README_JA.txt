■ 資料の読み取り(qa/reference_profile_IMG3591.json、reference_ledger_CAB04.*)
 - 左端のシルエットに、本体の側面より外へ出る段が 3 つある。
     張り出し: 笠木 25.5 / 中段 20.5 / 下段 14.5 px
     高さ: 16 / 24 / 14 px と、8 px の曲線状の移行部
 - 正面の帯の中には、上 2 段の下に影の線が 2 本ある → 段の数(3)と一致(確度 中〜高)。
 - 区別したもの:
     段差・輪郭 = シルエットの 3 つの平坦部
     影 = 正面帯の暗い 2 行
     モアレ = 画面全体の網目(不使用)
     遮蔽 = 右端と奥行き(人物)。左右対称を仮定
     斜め投影 = 横と縦の縮尺が違うので、同じ軸の比だけを使用
 - 推定: 最下段の曲線(cove)は小さすぎて形が読めないので、平らな段にまとめた。前方への出も読めないので、側面と同じ比にした。

■ C4 の形(previews/section_side_C3m_vs_C4.png)
 既存の上部帯(z 0.7182〜0.80)と既存天板の外形(x ±0.44、前面 y −0.28)の中だけで、3 段にした。上端 0.80 は変えていない。
   笠木  = 既存天板の箱(頂点 384〜479)。下面を 0.74 → 0.7779 に上げただけ。張り出し 16.0mm、高さ 22mm
   中段  = 新規。天板の箱を複製(同じトポロジ・UV・法線)。張り出し 13.4mm、前面 −0.2771、z 0.7462〜0.7784
   下段  = 既存モールの箱(頂点 576〜671)。張り出し +9.6mm(以前は −5.9mm の内側)、前面 −0.2728、z 0.7182〜0.7467
 張り出しの比は 16 : 13.4 : 9.6 = 資料の 25 : 21 : 15。段の継ぎ目は 0.5mm 埋め込み(同一平面によるちらつきを避けるため)。
 各箱は、両端の面取りを剛体のまま動かし、平面だけを伸縮した → 面の向きは不変。
