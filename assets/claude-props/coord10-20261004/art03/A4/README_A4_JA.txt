■ 変更内容 (A4/A4/build_A4.json)
 - 対象: Frame_22 のオリーブ色額面のみ(FinishAtlas olive セル)。マット/内リム/裏板/絵の面は形状・UVとも不変(qa/check_A4.json)。

 - 切断対象: バー前面の平らな帯(法線y≤−0.95)と、それに接するベベル1列。押し込みはこの集合の内部頂点だけ(616頂点)。
   その外側の面は辺上に頂点が入るだけなので、その16個のn角形は中心点で扇分割し、ゼロ面積三角形を防いだ。
 - 外寸・原点・軸・単位(UnitScaleFactor 100)・取付面(y=0背面)は不変。ソースの頂点1208個は位置不変で、頂点2392個を追加。
 - UV: 既存UVを分割面に補間(olive セルは単色で見た目への影響なし)。法線: ソースと同じフラット(カスタム法線=面法線)。
 - 三角形: 2444 → 7228 (約2.96倍)。非多様体辺 52 / 境界辺 0 / ゼロ面積 0 はソースと同等。
 - 縮小三角形による交差テスト: 非隣接の交差 386件はソースと同数(ソースの重なり面に由来。新しい貫通はなし)。
