■ CUT02_A1 の形(qa/dimensions_before_after.json)
 共通: 全長と Y の両端位置、長軸 +Y、上 +Z、z=0 接地、原点、単位(m、UnitScaleFactor 1.0)、材質 slot 1 つ(Trussardi_Atlas)は原本と同じ。
 フォーク(1264 tri)
   - 4 歯(根元 4.0 → 先 2.6mm、歯の間 3mm、V 字の歯底)
   - 肩は S 字で丸く絞り、首幅 7.4mm。柄は細く(端の付近で幅 14.9 → 11.5mm)、端は丸い
   - 側面は柄の端で接地し、頭へ緩く反る。頭は横方向にわずかに匙状
   - 作り方: 上面のグリッドを押し出し、高さ方向に曲げた
 スプーン(1656 tri)
   - 楕円の椀(38×71mm)、深さ 6.2mm、肉厚 1.3mm。縁は薄い
   - 首は細く(6.8mm)、柄は 12.3mm へ連続。椀の裏が接地する
   - 作り方: 断面を連ねたロフトで、凹んだ上面と裏面を持つ一体の閉じたメッシュ
 ナイフ(912 tri)
   - 刃幅 20mm。先端は刃幅の半円で丸め、刃側の輪郭は滑らかな曲線(PCHIP)
   - 刃は背 1.9mm → 刃先 0.5mm のくさび
   - 首 9mm を経て、丸い断面の柄(幅 12mm、厚み 4.2mm)へ連続
 三角形: 3 点の合計 3832(原本 3100、24 組で約 9.2 万 tri)。
 高さ: フォーク 13.7 → 11.3mm、スプーン 22.0 → 10.5mm(深すぎた椀を常識的な深さへ)、ナイフ 3.0 → 4.35mm(丸い柄)。

■ UV / 法線
 - UVMap(UV0): 原本が使っている均一な銀色の領域(BaseColor の std は約 2)の中へ、上面から平面投影。
 - LightmapUV(UV2): 新しく重なりのない展開(1024² で重なる画素 0)。
 - 法線: 新しい曲面からスムーズに計算し、48° 以上の角は sharp。旧モデルの UV/法線のコピーや、旧モデル全体への再計算はしていない。
