CAB03 袖壁の戸棚 C3（窓・框の割合）と C3m（C3＋上下モールの段差）。K2 を基準にした形状だけの候補
担当: Claude（クラウド）。実行環境: pip の bpy 4.3.0（Cycles CPU）。Blender 5.2.2 と Unity は実行していない（独立検査・配置・色合わせは元 Codex）
- 基準: furniture/wall_cabinet/K2（source FUR06 @ 6b8c26f の扉範囲を伸ばした形）。K0・K1・K2・入力は上書きしていない
- 優先資料: IMG_3591（ユーザーが今回貼った 2 画像と同じカット）を実際に見た。元画像・切抜きはこのリポジトリに含めない
- 部位別の台帳: reference_ledger_CAB03.csv / .json（画像、部位、透視、可視根拠、確信度、対応）

■ 参考と K2 の差（IMG_3591。左の扉で計測。比率は未校正の目安）
- 窓: 参考は扉幅の約 0.6 で、ほぼ正方形。K2 は扉幅の 0.86 で縦長、框は細い（縦框 2.7 cm ≈ 扉幅の 7%）
- 框: 参考は縦框が扉幅の約 0.19 と太い。上框が最も太く、中央の横框はやや細い
- 上下: 参考は段付きの冠木と 2 段の台輪で、影の帯が出る。K2 は板と細い帯がほぼ面一で、段差が弱い
- 取手: 中央の横框の高さで、合わせ目の近くに丸い取手が 2 つ（K2 と同じ構成）
- 透視と遮蔽
  - 左下から見上げる構図。右端と右側面は人物の頭で隠れる
  - 外形・奥行き・内部は数値化せず、作らない
  - 細かい網目は画面撮影のモアレで、材質の柄ではない
- 色（参考、相対値）: 木部は濃い焦げ茶（RGB ≈ 47,39,34）、窓は低彩度の灰緑（≈ 77,85,79）、取手は鈍い黄緑の金（≈ 82,84,48）

■ C3（窓と框だけ。既存の面構成の範囲で変更）
- 扉枠・ガラス・中央の横框の頂点を、扉ごとに区間ごとの線形写像で動かした
  - 面取りの帯（外周 2.4 mm、内周 2 mm）の幅は保持
- 窓の幅: 扉幅の 0.86 → 0.62（各扉の窓の幅 0.332 → 0.239 m）。縦框 2.7 → 7.35 cm
- 上框 3.9 → 8.5 cm、下框 4.3 → 6.5 cm、中央の横框 4.2 → 4.8 cm（中心の高さは保持）
- 中央の横框の両端は、新しい縦框の内側の縁に合わせた（縦框の前面に飛び出さない）
- 取手: 74 頂点のまま剛体の平行移動（丸さを保持）。太くした合わせ目側の縦框の中央へ（右 +1.07 cm、左は対称）
- 不変
  - 外寸 0.88×0.301×0.80 m、原点（下端 z=0）、取付けの基準、側板・背板・天板・台輪
  - UV（FurnitureUV）、index、loop→頂点の対応、三角形数 4220、材質と自作 texture（FinishAtlas_FUR06.png はバイト同一の複製）
- 動いた頂点: 1124（番号 673〜2131。扉枠・ガラス・中央の横框・取手）
  - 一覧: C3/vertex_delta_vs_K2_C3.csv（Blender 座標）
- 法線: 動いた corner は、写像の逆転置で変換した
  - 動いていない頂点の corner 法線の差は最大 4.7e-4（1e-3 を超えるものは 0）。カスタム法線の再エンコード誤差（K2 でも同じ水準）
- 交差: 中央の横框と枠（94）、ガラスと枠（68）の重なりは K2 と同数（元の設計の埋込み）。新しい交差は無い。取手は枠・ガラスと交差 0
■ C3m（C3 ＋ 上下のモールの段差だけ）

- 板の張り出しが段として見え、影が出る。外寸は不変。新しい形状は追加していない（頂点の対応は全て保持）
- 動いた頂点: 1316（番号 480〜2131）。一覧: C3m/vertex_delta_vs_K2_C3m.csv
